小孟蜜汁系统 使用说明
====================

一、实体按键
左上: KEY1、KEY2
右上: KEY3、KEY4
左下: SW2
右下上: KEY5
右下下: KEY6
另有五向方向开关。

通用逻辑:
KEY1: 返回/主页（部分功能中有特殊用途）
KEY2: 选项；NES 游戏中音量+
KEY3: 返回；NES 游戏中为 SELECT
KEY4: 确定/进入；NES 游戏中为 START
SW2: 主界面切换灯光模式；NES 游戏中音量-
KEY5: 增加/上一项；NES A
KEY6: 减少/下一项；NES B
五向: 菜单导航；NES 十字键

二、电子书
1. 将 .txt 放入 SD 卡 /books 目录。
2. 支持 UTF-8、UTF-16 LE/BE、常见 GBK/GB2312。
3. 阅读中: 上/左/KEY5=上一页，下/右/KEY6=下一页。
4. KEY3 或 KEY1 退出时自动保存该书阅读进度。

三、音乐
1. 将 .mp3 或 PCM16 .wav 放入 SD 卡 /music 目录。
2. 音乐列表可浏览全部歌曲，KEY4 开始播放。
3. 播放页左/右切上一首/下一首，KEY4 播放/暂停。
4. KEY5 音量+，KEY6 音量-，KEY3/KEY1 停止并返回。
5. 当前歌曲正常播放结束后自动播放下一首，最后一首结束后回到第一首。

四、NES
ROM 放入 /games 目录。
游戏中五向=方向，KEY5=A，KEY6=B，KEY3=SELECT，KEY4=START，
KEY2=音量+，SW2=音量-，长按 KEY1 约 1 秒退出 NES。

五、系统信息
KEY5 可重新检测 SD 卡；KEY3/KEY1 返回。

更完整的按键说明请查看 GitHub 仓库 README.md。

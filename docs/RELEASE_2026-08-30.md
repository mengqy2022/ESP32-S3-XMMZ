# 2026-08-30 GitHub 版修改说明

> 已归档。版本演进见 [`CHANGELOG.md`](../CHANGELOG.md)。

## 界面

- 主界面右上角显示 `YYYY-MM-DD HH:MM`。
- 日期时间只在分钟变化时刷新，降低顶部状态栏的无效重绘。
- 系统信息页重新压缩行距并划分固定正文区/底部提示区，修复文字重叠。

## 电子书

- 删除旧版 `MAX_FILE_SIZE = 4 MB` 的整本载入模式。
- SD TXT 改为 4 KB 流式 I/O + 动态页索引，大型小说不再需要把全文常驻 PSRAM。
- 支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE、常见 GBK/GB2312。
- 文件名缓冲扩大到 256 字节，完整路径扩大到 320 字节，兼容 FATFS UTF-8 长文件名。
- 书单改为 5 行虚拟列表，只维护可见 LVGL 对象。
- 书签改为按书路径哈希后的 NVS key 独立保存；保留旧版 `book/page` 书签迁移逻辑。
- 打开大型书时先显示“正在建立分页索引...”反馈，避免误判为卡死。

## 稳定性 / 内存

- 主菜单重建时使用 LVGL 自动删除旧屏，避免应用进出后屏幕对象树累积。
- 图库和 NES 全屏页面同样接入统一屏幕生命周期管理。
- 电子书退出时明确释放页缓冲、I/O 缓冲、分页索引和书目元数据。
- 系统信息页可实时查看空闲堆、最低空闲堆、PSRAM 可用量，便于长期运行观察。

## GitHub 清理

发布包不包含：

- `managed_components/`
- `build/`
- `sdkconfig` / `sdkconfig.old` / 备份
- 历史 patch、日志、一次性修复报告

保留 `dependencies.lock`、`main/idf_component.yml`、`sdkconfig.defaults`，便于克隆后恢复依赖。

## 本轮补充（按键 / 自动续播 / ESP32-S3 构建）

- README 增加完整实体按键位置和各应用按键功能矩阵：KEY1~KEY6、SW2、五向方向键。
- 音乐自然播放结束后自动播放下一首，最后一首结束后循环第一首；手动停止/切歌不会误触发自动续播。
- 音乐播放页只在状态/音量变化时更新 LVGL 标签，并缩短暂停/停止轮询粒度，提高切歌和恢复手感。
- 主菜单和 NES 页面可见名称由“NES 模拟器”改为“NES”。
- 公共应用顶栏原 `v0.3` 标签改为“不要狗叫”，真实固件版本仍保留在 `SYS_VERSION_STR`。
- `sdkconfig.defaults` 增加 `CONFIG_IDF_TARGET="esp32s3"`，根 `CMakeLists.txt` 同时锁定 ESP32-S3，避免 ESP-IDF 在未选 target 时默认回落到经典 ESP32。
- `board_config.h` 增加 ESP32-S3 编译期保护，若目标错误会直接给出明确提示。
- 修复 ESP-IDF 5.5.4/GCC 14 下日期格式和电子书超长文件名触发的 `-Werror=format-truncation`。

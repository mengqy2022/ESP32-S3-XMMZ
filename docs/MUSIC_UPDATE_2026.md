# 小孟蜜汁系统 — 音乐功能更新

本次仅追加音乐模块需求，其余 UI 和系统功能保持上一版修改结果。

## 已完成

1. **完整曲库浏览**
   - 不再只提供前 5 首歌曲。
   - 不再固定最多 24 首。
   - SD 卡 music 目录中的全部可播放 MP3/WAV 会进入曲库。
   - 采用 5 行虚拟化显示窗口，方向键可浏览整个曲库，同时控制 LVGL 对象数量以保持流畅。

2. **播放页上一首 / 下一首**
   - 左键：上一首。
   - 右键：下一首。
   - 首尾循环。
   - 切歌时同步更新歌曲名、来源和“当前 / 总数”。

3. **切歌稳定性**
   - 新曲目路径写入前先停止旧播放任务，避免快速切歌时共享源路径竞态。

## 保持不变

- KEY4：播放 / 暂停。
- KEY5(A)：音量 +。
- BOOT / KEY6(B)：音量 -。
- KEY3 / HOME：停止并返回。
- MP3 / WAV 本地播放和网络 MP3 备用逻辑保持。

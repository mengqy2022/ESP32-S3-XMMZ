# 小孟蜜汁系统 — UI 重设计说明（2026）

## 目标

本次改版在不改变原有应用功能和按键逻辑的前提下，统一视觉层级、减少界面拥挤，并针对 ESP32-S3 + ST7789 + LVGL 的资源约束优先保证流畅和稳定。

## 视觉主题

- 品牌名统一为 **小孟蜜汁系统**。
- 采用 Apple Dark 风格的深色调色板：深黑背景、分层灰色卡片、系统蓝强调色、高对比文字。
- 页面边距统一为 10px，卡片圆角 8px，焦点使用蓝色细边框而不是高成本阴影。
- 主界面改为 4 项/页，顶部品牌/时间/电量独立布局，底部操作提示固定，避免小屏内容互相重叠。
- 系统设置、WiFi、蓝牙、灯光、电子书、音乐、NES、游戏大厅、虚拟键盘统一使用公共卡片按钮样式。
- 图库、NES 实际游戏画面等全屏内容保留原有沉浸式显示方式。

## 流畅性与稳定性

- 主界面翻页动画由 350ms 缩短为 180ms，并在新动画开始前删除旧动画，防止快速连续按键叠加动画。
- 主题不使用透明模糊、渐变、大阴影等高重绘效果，保持纯色 + 细边框。
- 保留原工程单线程驱动 LVGL、内部 DMA 绘制缓冲、单缓冲等稳定性策略。
- 修复 WiFi 多次扫描时旧 AP 按钮可能无法删除的问题，避免 LVGL 对象持续累积导致内存下降和长期运行卡顿/崩溃。
- 修复游戏大厅首次焦点可能误命中标题栏（user_data=0 与 NULL 混淆）的问题。
- BLE 设备列表与设置/音乐列表重新压缩间距，避免底部提示与最后一项发生视觉重叠。

## 主要修改文件

- `main/apps/lvgl_ui.h/.c`：统一主题、公共卡片样式、标题栏样式。
- `main/apps/lvgl_menu.c`：主页完整重设计。
- `main/apps/app_login.c`：品牌化登录界面。
- `main/apps/app_settings.c`、`app_wifi.c`、`app_ble.c`、`app_led.c`、`app_ebook.c`、`app_music.c`、`app_nes.c`、`app_games.c`、`kbd.c`：统一控件样式与局部布局优化。
- `main/version.h`：系统显示名称更新为“小孟蜜汁系统”。

## 建议上板验证

1. 连续快速上下翻页 2–3 分钟，确认无动画卡死、焦点跳页正常。
2. WiFi 连续扫描 20 次以上，观察 free heap 不应随扫描次数持续下降。
3. BLE 扫描 8 个设备时确认底部提示不被覆盖。
4. 系统设置和音乐列表检查最后一行与底部提示之间的间距。
5. 进入/退出电子书、图库、NES、游戏、音乐各 10 次，确认主页重建和焦点恢复正常。

## 当前校验状态

- 已对修改文件做基础语法结构检查（括号/花括号平衡）。
- 新使用的 LVGL API 已在工程自带的 LVGL 9.5.0 源码中核对存在，包括 `lv_anim_delete`、`lv_obj_scroll_to_view`、`lv_obj_set_scrollbar_mode`、`lv_obj_set_style_border_side`。
- 已确认 `book_font_lvgl` 包含“蜜”“汁”字形，品牌名不会因为精简 UI 字库而缺字。

## 音乐功能追加更新（2026-08-30）

- 移除音乐列表原先“只显示前 5 首”的功能限制，以及底层固定 `MAX_TRACKS=24` 的曲库上限。
- SD 卡 `/sdcard/music` 改为先扫描全部可播放 MP3/WAV，再按实际曲目数量动态分配曲库元数据；优先使用 PSRAM，失败后回退内部 RAM。
- 曲库排序由 O(n²) 冒泡排序改为 `qsort`，大量歌曲时进入音乐页面更快。
- 列表使用 5 行虚拟化窗口：方向键可从第一首连续浏览到最后一首，但 LVGL 始终只维护最多 5 个歌曲按钮，避免曲库较大时创建大量对象造成卡顿或内存压力。
- 列表底部显示当前浏览范围与总曲数，例如 `6-10 / 87`。
- 播放页面新增左右键切歌：`←` 上一首、`→` 下一首；首尾循环。
- 播放页面新增当前曲目序号，例如 `3 / 87`，切歌时同步更新曲名和来源。
- 修复快速切歌时共享播放源 `s_src` 的竞态：先停止旧播放任务，再写入新路径/URL，降低连续切歌时误开文件的风险。

### 音乐功能上板验证建议

1. 在 SD 卡 `/music` 放入至少 10 首 MP3/WAV，确认可从第 1 首一直向下浏览至最后一首。
2. 放入超过 24 首歌曲，确认不再被旧的 `MAX_TRACKS=24` 截断。
3. 在播放页连续按左右键切换 20 次，确认曲名、序号、实际播放内容一致。
4. 在第 1 首按左键应循环到最后一首，在最后一首按右键应循环到第 1 首。
5. 同时测试 MP3、WAV 与网络备用曲目，确认播放/暂停、音量加减、返回逻辑仍正常。

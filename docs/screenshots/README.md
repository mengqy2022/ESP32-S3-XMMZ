# 截图目录

在此目录放入界面截图，便于在 README / 文档中引用。

## 建议命名

| 文件 | 内容 |
|---|---|
| `home.png` | 主界面 |
| `settings.png` | 系统设置 |
| `music.png` | 音乐播放 / 列表 |
| `ebook.png` | 电子书阅读 / 书单 |
| `gallery.png` | 图库 |
| `nes.png` | NES 游戏 |
| `games.png` | 内置小游戏 |

> 384×288 或更高分辨率（保持 4:3）即可；截图请勿包含个人隐私信息（如 WiFi 密码、MAC 地址等）。

## 引用方式

在 `README.md` 中：

```markdown
![主界面](docs/screenshots/home.png)
```
